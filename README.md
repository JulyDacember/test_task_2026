**Результаты первичного анализа кода для выявления возможных проблемных мест, замедляющих работу:**

| Файл | Проблема | Последствие |
|---|---|---|
| `main.py` | Запрос к БД выполняется для каждого покупателя | Большое количество SQL-запросов |
| `main.py` | `commit()` после каждого покупателя | Лишние транзакционные накладные расходы |
| `abstract_customer.py` | `commit()` внутри `create_or_update_lead()` | Много отдельных транзакций |
| `main.py` | Повторное чтение всей таблицы при очистке | Дополнительная нагрузка на БД и память |
| `main.py` | Ошибки обработки сделок перехватываются, но синхронизация продолжается | Очистка может запуститься после неудачной выгрузки |
| `main.py` | При объединении записей `lead_action()` возвращает `None` | Возникает ошибка при обращении к `abc_customer.id` |
| `abstract_customer.py` | Новый объект добавляется в сессию без `flush()` | Его `id` может быть ещё не получен при заполнении `ids_map` |
| `main.py` | Ошибка в фильтрации вложенных сущностей | Некорректная очистка данных |

Для прогона был написан генератор тестовых данных. Типы сгенирированных данных:
| Тип данных | Количество |
|---|---:|
| Покупатели | 1 000 |
| Сделки | 2 500 |
| Покупатели без логина | 50 |
| Сделки без логина | 100 |
| Сделки с логином существующего покупателя | 1 500 |
| Сделки с неизвестным логином | 500 |
| Сделки с неоднозначным логином | 100 |
| Остальные сделки | 300 |
